  <div class="u058-body" tabindex="0" aria-label="Article">
    <h4>Intro</h4>
    <p>The 0.3 seconds after a tap when nothing happens is longer than you think. People read that brief silence as “broken.”</p>
    <p>So good transitions respond first and show the result later. When something moves the instant you press, waiting stops feeling like waiting.</p>
    <h4>Three principles</h4>
    <p>First, start where the finger landed. Second, move only what changes. Third, when stopping, overshoot slightly and settle back.</p>
    <div class="u058-fig" aria-hidden="true"></div>
    <p>Keep just these three and a screen feels far less stiff. The third one in particular adds a sense of weight.</p>
    <h4>In practice</h4>
    <p>When a product flies into the cart icon, people follow the result with their eyes. It leads to fewer mistakes than a number quietly changing.</p>
    <p>When the highlight slides between tabs, you can still tell where you came from. It keeps people from getting lost.</p>
    <p>The same goes for deleting from a list. When the items below slowly close the gap, you naturally see what was removed.</p>
    <h4>Wrap-up</h4>
    <p>Transitions aren’t decoration but explanation — the shortest sentence for what went where.</p>
    <p>Too long and it turns into waiting; too short and no one sees it. Most answers lie between 0.2 and 0.5 seconds.</p>
    <p>And for people who prefer less motion, deliver the same information without it. That is part of a good transition too.</p>
    <div class="u058-end">You reached the end · Here’s what to read next</div>
  </div>
</div>
<script>
(function () {
  var root = document.currentScript.previousElementSibling;
  var body = root.querySelector('.u058-body'), toc = root.querySelector('.u058-toc'), pill = root.querySelector('.u058-pill');
  var ring = root.querySelector('.u058-ring'), pct = ring.querySelector('span');
  var rm = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
  var hs = Array.prototype.slice.call(body.querySelectorAll('h4'));
  var btns = hs.map(function (h, i) {
    var b = document.createElement('button');
    b.type = 'button'; b.textContent = ['Intro', 'Principles', 'Examples', 'Wrap-up'][i];
    b.setAttribute('aria-label', 'Go to ' + h.textContent);
    b.addEventListener('click', function () { body.scrollTo({ top: h.offsetTop - 8, behavior: rm ? 'auto' : 'smooth' }); });
    toc.appendChild(b);
    return b;
  });
  var act = -1;
  function mark(i) {
    if (i === act) return;
    act = i;
    btns.forEach(function (b, k) { b.setAttribute('aria-current', String(k === i)); });
    pill.style.setProperty('--x', btns[i].offsetLeft + 'px');
    pill.style.setProperty('--w', btns[i].offsetWidth + 'px');
  }
  function sync() {
    var max = body.scrollHeight - body.clientHeight, p = max > 0 ? Math.min(1, body.scrollTop / max) : 1;
    root.style.setProperty('--p', p.toFixed(4));
    ring.style.setProperty('--p', p.toFixed(4));
    pct.textContent = Math.round(p * 100) + '%';
    ring.setAttribute('aria-valuenow', Math.round(p * 100));
    root.classList.toggle('is-done', p > 0.985);
    var i = 0;
    hs.forEach(function (h, k) { if (h.offsetTop - 60 <= body.scrollTop) i = k; });
    if (p > 0.985) i = hs.length - 1;
    mark(i);
  }
  body.addEventListener('scroll', sync, { passive: true });
  sync();
  if (window.ResizeObserver) new ResizeObserver(function () { var a = act; act = -1; mark(a); }).observe(toc);
})();
</script>
